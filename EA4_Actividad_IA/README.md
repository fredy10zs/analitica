# EA4 — Actividad con IA: Análisis de carga de vehículos eléctricos

## Pregunta guía
¿De qué manera influyen la temperatura ambiental y la hora del día en la eficiencia de recarga y la autonomía proyectada de las flotas de vehículos eléctricos?

## Estructura
- `datos/`: archivos de datos descargados desde Hugging Face.
- `EA4_Fredy_Ramírez.ipynb`: desarrollo documentado y análisis.
- `requirements.txt`: dependencias del entorno.

Los resultados y conclusiones se documentarán tras ejecutar el análisis con los datos reales; no se anticipan ni inventan hallazgos.
